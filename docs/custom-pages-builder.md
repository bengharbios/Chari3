# 🌐 منشئ الصفحات المخصصة (Custom Pages Builder)

يتيح لك هذا النظام إنشاء صفحات مخصصة بالكامل لمنصتك (مثل: من نحن، سياسة الخصوصية، الشروط والأحكام، والأسئلة الشائعة) باستخدام واجهة **السحب والإفلات (Drag & Drop)** القوية، وبناءها مرة واحدة لجميع اللغات!

## ⚙️ التقنية المستخدمة
تم الاعتماد على محرك **[Puck Editor](https://github.com/puckeditor/puck)** لبناء الصفحات، لأنه متوافق تماماً مع `Next.js` و `React`.

## ✨ ميزة الترجمة الذكية (Multi-Language)
بدلاً من إنشاء الصفحة 3 مرات وتكرار التصميم، قمنا بتخصيص محرك Puck ليصبح **متعدد اللغات داخلياً**:
1. عند سحبك لأي عنصر (مثل "نص" أو "عنوان").
2. انظر إلى القائمة الجانبية (Sidebar) يمين الشاشة.
3. ستجد حقلاً منفصلاً لكل لغة: (محتوى عربي، محتوى إنجليزي، محتوى فرنسي).
4. املأ جميع الحقول واضغط **"نشر - Publish"**.
5. النظام سيكتشف لغة الزائر تلقائياً ويعرض له النص المناسب بنفس التصميم الذي اعتمدته!

## 🛠️ كيفية الاستخدام

### 1. إضافة صفحة جديدة
- اذهب إلى **لوحة التحكم > الصفحات المخصصة**.
- اضغط على **"إنشاء صفحة جديدة"**.
- أدخل الرابط (مثال: `privacy-policy` أو `about-us`). يجب أن يكون باللغة الإنجليزية وبدون مسافات.
- أدخل عناوين الصفحة.
- اضغط "حفظ ومتابعة التصميم".

### 2. تصميم الصفحة
- ستفتح لك واجهة المحرر المرئي (Builder).
- من القائمة اليسرى، يمكنك سحب العناصر المتاحة (Hero, Text, Section) وإسقاطها في المنتصف.
- انقر على أي عنصر قمت بإضافته، لتظهر لك خصائصه في القائمة اليمنى.
- قم بتعبئة النصوص باللغات الثلاث.
- عند الانتهاء، اضغط على زر **Publish** (نشر/حفظ) في أعلى الشاشة.

### 3. تفعيل ونشر الصفحة للجمهور
- بعد الانتهاء من التصميم، عُد إلى قائمة الصفحات.
- بشكل افتراضي، تكون الصفحة مسودة (Draft) ولا يراها الزوار.
- اضغط على أيقونة **(الكرة الأرضية / نشر)** لجعل الصفحة متاحة للجميع.
- يمكن الآن لأي شخص زيارة الصفحة عبر الرابط: `https://chariday.com/pages/your-slug`

## 👨‍💻 للمطورين: كيفية إضافة مكونات جديدة (Components)
إذا أردت إضافة مكونات مرئية جديدة للمحرر (مثلاً: أزرار، بطاقات، جداول أسعار)، يمكنك ذلك بسهولة عبر تعديل ملف `src/lib/puck/config.tsx`.

مثال لإضافة مكون "زر" (Button):
```tsx
Button: {
  fields: {
    labelAr: { type: "text", label: "Button Label (Ar)" },
    labelEn: { type: "text", label: "Button Label (En)" },
    labelFr: { type: "text", label: "Button Label (Fr)" },
    url: { type: "text", label: "Link URL" },
  },
  defaultProps: {
    labelAr: "اضغط هنا",
    labelEn: "Click Here",
    labelFr: "Cliquez ici",
    url: "#"
  },
  render: ({ labelAr, labelEn, labelFr, url }) => {
    const locale = usePuckLocale();
    const label = locale === 'en' ? labelEn : locale === 'fr' ? labelFr : labelAr;
    return (
      <a href={url} className="btn-primary">
        {label}
      </a>
    );
  }
}
```
